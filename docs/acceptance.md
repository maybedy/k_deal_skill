# 수용 시험

## 로컬 검증

- manifest 이름·버전·경로와 marketplace 참조가 일치하는지 확인한다.
- 스킬 4개와 스크립트·카탈로그가 포함되고 키·DB·개인 경로·캐시가 포함되지 않았는지 확인한다.
- API 파라미터, 페이지 일부 응답, 정상 0건과 오류의 구분, 키가 오류에 노출되지 않는지를 단위 테스트한다.
- ZIP을 다시 열어 목록·경로·CRC와 SHA-256을 확인한다.

테스트용 응답은 원자료로 인용하지 않는다.

## 새 사용자가 설치 후 확인할 사항

| 질문 | 기대 결과 |
|---|---|
| 지정 회사의 2025년 연결 재무제표 조회 | 법인 식별·사업연도·보고서 코드·CFS·접수번호/출처 표시 |
| 같은 회사의 최대주주 현황·타법인 출자현황 | `report` 실행 결과와 보고서 기준연도 표시 |
| 지정 거래일의 KRX 종가·시가총액·상장주식수 | 입력 기준일·시장·원천 출처 보존. 0건을 임의 가격으로 채우지 않음 |
| 승인받지 않은 KRX 서비스 호출 | `not_approved` 오류. 빈 결과로 표시하지 않음 |
| 사업자등록번호 휴폐업 확인 | 국세청 상태 코드와 조회 시각 표시 |
| 상법 특정 조문과 과거 시행일 조문 | 법령 ID·시행일·조회 시각 구분 |
| OC 없는 사용자의 법령 조회 | 원격 법령 MCP로 조회하고 그 사실 표시 |
| 키·네트워크가 없는 새 사용자 | 키를 채팅에 입력시키지 않고 필요한 신청·설정을 설명 |
